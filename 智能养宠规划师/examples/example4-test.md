# 示例4：金毛寻回犬月度规划（推断确认 + 修正体重版）

## 用户提问

**第 1 轮**：

```
我有一只金毛，年龄 5 岁需要你做一份预算。
```

**第 2 轮**：

```
体重有 27kg，已经绝育。
```

## Skill 回答

### 🐾 金毛寻回犬 本月养宠指南

> 金毛寻回犬 · 5岁 · 27kg · 已绝育 · 无特殊需求

#### 🍖 本月喂什么

| 餐次 | 时间  | 食物             | 用量  |
| ---- | ----- | ---------------- | ----- |
| 早餐 | 07:30 | 全价大型犬成犬粮 | 155 g |
| 加餐 | 12:00 | 主食罐           | 100 g |
| 晚餐 | 18:30 | 全价大型犬成犬粮 | 155 g |

- 每日总量：310 g 干粮 + 100 g 湿粮（约 **1326 kcal/天**，RER×1.6）
- 零食：≤ 130 kcal/天，仅训练奖励使用
- 饮水：≥ 1500 ml/天（自动饮水机 + 外出补水）
- 禁忌：巧克力/葡萄/洋葱/澳洲坚果致命；进食后 1 小时禁剧烈运动（防胃扭转）

#### ✅ 本月做什么

- [ ] 体外驱虫（每月必做，4-10 月蚊虫高发期）
- [ ] 体内驱虫（每 3 个月 1 次）
- [ ] 洗澡 + 彻底吹干（每 7-10 天 1 次，双层被毛腋下/指缝别漏）
- [ ] 剪指甲 + 挤肛腺 1 次
- [ ] 称重 1 次（若 > 29 kg 需减食 10%，金毛易发胖）
- [ ] 每日散步 45-60 分钟（金毛运动量需求高，避免剧烈跑跳）

#### 💰 月度开销

| 项目     | 金额       |
| -------- | ---------- |
| 🥩 饮食   | 450 元     |
| ✂️ 美容  | 180 元     |
| 💊 医疗   | 120 元     |
| 🎽 用品   | 80 元      |
| **合计** | **830 元** |

#### ⚠️ 注意事项

1. **髋关节发育不良（CHD）高发**：年度体检加做髋关节 X 光，避免楼梯跳跃、长期站起；体重控制是核心预防手段
2. **胃扭转（GDV）高危**：分 2-3 餐喂食、禁饭后立即剧烈运动、用慢食碗，若腹胀+干呕+大量流口水 2 小时内就医
3. **皮肤过敏+耳道感染**：洗澡后彻底吹干、每周擦耳 1 次，若频繁抓痒/掉毛需查过敏源

## 假设说明

用户两轮加起来给了品种、年龄、体重、绝育状态，其他字段是假设的：

| 字段            | 第 1 轮推断值                     | 用户第 2 轮修正了没               | 最终采用值      |
| --------------- | ---------------------------------- | ------------------------------------- | --------------- |
| weight_kg       | 29.5 kg（金毛大型犬成犬中位）      | ✅ 修正                                | **27 kg**       |
| sterilized      | 已绝育（城市养宠默认）             | ✅ 确认                                | **已绝育**      |
| age_months      | 60 个月（5 岁）                    | — 用户已给出                          | 60 个月         |
| 体型评分（BCS） | 5/9（标准体型）                    | — 体型评分不确认直接用标准             | 5/9             |
| 功能性需求      | 空（用户未提）                     | —                                     | 无              |
| 价格基准        | 二线城市中位值                     | —                                     | 二线城市        |

如果用户没有第 2 轮修正（完全用第 1 轮推断），结果会差多少：

- 每日热量：1433 kcal（而非 1326 kcal）
- 每日干粮量：~340 g（而非 310 g），每天多喂 30 g，一个月胖 ~0.5 kg
- 少一轮交互，但精度差不少
