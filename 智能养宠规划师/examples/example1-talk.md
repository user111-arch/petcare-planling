# 示例1：金毛寻回犬月度规划

## 用户提问

```
我有一只金毛寻回犬，3 岁，体重 29.5kg，已绝育，帮我做一份月度养宠规划。
```

## Skill 回答

# 🐾 金毛寻回犬 本月养宠指南

> 金毛寻回犬 · 3岁 · 29.5kg · 已绝育 · 无特殊需求

## 🍖 本月喂什么

| 餐次 | 时间  | 食物                      | 用量       |
| ---- | ----- | ------------------------- | ---------- |
| 早餐 | 08:00 | 大型犬成犬粮 + 三文鱼油   | 250g + 1粒 |
| 晚餐 | 18:00 | 大型犬成犬粮 + 冻干鸡胸肉 | 250g + 20g |

- 每日总量：500g 干粮（约 1300 kcal）
- 零食：≤ 130 kcal/天（训练奖励用）
- 饮水：≥ 1600 ml/天
- 禁忌：葡萄/巧克力/洋葱致命；绝育后易胖，严禁自助餐

## ✅ 本月做什么

- [ ] 体外驱虫（每月必做，4-10月高发期）
- [ ] 体内驱虫（每3个月1次，本月到期）
- [ ] 洗澡 1 次 + 剪指甲 + 挤肛腺
- [ ] 每日梳毛 15 分钟（换毛季减少家里掉毛）
- [ ] 称重 1 次（若 > 31kg 需减食 10%）
- [ ] 每日运动 ≥ 90 分钟（散步 2 次 + 跑动 1 次）

## 💰 月度开销

| 项目     | 金额       |
| -------- | ---------- |
| 🥩 饮食   | 450 元     |
| ✂️ 美容  | 180 元     |
| 💊 医疗   | 120 元     |
| 🎽 用品   | 80 元      |
| **合计** | **830 元** |

## ⚠️ 注意事项

- 金毛高发髋关节发育不良（CHD），避免频繁跳高和剧烈爬楼梯
- 运动后 30 分钟内不要大量进食或饮水，预防胃扭转
- 9 月需接种窝咳疫苗加强针，建议提前预约

## 假设说明

1. 体型评分（BCS）：**5/9（标准体型）** — 若实际偏胖/偏瘦，喂食量需相应调整
2. 功能性需求：**无** — 金毛常见的关节护理/皮肤护理/化毛需求未开启
3. 所在城市接种/驱虫价格：**取全国二线城市中位值** — 一/三线城市 ±15% 浮动属正常

> 以上如有不符请直接告知，会重新算。
