# 示例3：英国短毛猫月度规划（预算 400 元 + 泌尿+化毛）

## 用户提问

```
我有一只英国短毛猫，3 岁，6kg，已绝育，我想把每月开销控制在 400 元以内，帮我写一份规划。
```

## Skill 回答

# 🐾 英国短毛猫 本月养宠指南

> 英国短毛猫 · 3岁 · 6kg · 已绝育 · 💧泌尿护理 + 🧶化毛

## 🍖 本月喂什么

| 餐次 | 时间  | 食物                          | 用量         |
| ---- | ----- | ----------------------------- | ------------ |
| 早餐 | 08:00 | 平价全价成猫粮 + 蛋黄（每周2次） | 35g          |
| 晚餐 | 19:30 | 平价全价成猫粮 + 少量湿粮（每周3次） | 30g / 30g 湿粮 |

- 每日总量：约 65g 干粮 + 10g 湿粮（约 290 kcal）
- 零食：≤ 15 kcal/天（控制预算，不买冻干/猫条，用自制鸡胸碎代替）
- 饮水：≥ 350 ml/天（多加水盆，帮助泌尿保健，不额外买饮水机）
- 禁忌：禁高镁食物；干粮为主必须督促喝水

## ✅ 本月做什么

- [ ] 体外驱虫（每月必做，不削减）
- [ ] 体内驱虫（每3个月1次，本月到期，不削减）
- [ ] 每日梳毛 5-10 分钟（替代化毛膏节省预算）
- [ ] 每周称重 1 次（目标 ≤ 5.8kg）
- [ ] 居家剪指甲 + 挤肛腺（不送宠物美容店节省预算）
- [ ] 每日逗猫棒 15 分钟
- [ ] 蛋黄 2-3 次/周（美毛 + 卵磷脂替代保健品）

## 💰 月度开销

| 项目     | 标准   | 您的预算 |
| -------- | ------ | -------- |
| 🥩 饮食   | 250 元 | 213 元   |
| ✂️ 美容  | 60 元  | 51 元    |
| 💊 医疗   | 100 元 | 85 元    |
| 🎽 用品   | 60 元  | 51 元    |
| **合计** | **470 元** | **400 元** |

> 您的预算低于品种标准 70 元。饮食方面平价全价粮替代功能性粮、自制鸡胸肉代替猫条冻干；美容改为居家剪指甲洗澡；用品仅补充消耗品；驱虫疫苗保留不削减。

## ⚠️ 注意事项

- 英短公猫高发泌尿问题，频繁蹲猫砂盆无尿需 24 小时内就医
- 易胖体质，严禁自助餐，严格按克数喂食
- 多囊肾病（PKD）高发，预算允许后年度体检加做肾脏 B 超

## 假设说明

1. 体型评分（BCS）：**6/9（略偏胖 10%）** — 绝育系数 1.2，目标月末 ≤ 5.8kg
2. **功能性需求：泌尿护理 + 化毛** — 英短高发问题主动叠加；化毛用每日梳毛替代化毛膏、泌尿用多喝水+勤换水替代泌尿粉以节省预算；如实际无泌尿症状且短毛季掉毛少，可取消对应护理
3. 公/母猫：假设**公猫**（泌尿风险更高）；母猫且无泌尿史可降级泌尿护理
4. 所在城市价格：二线城市中位值，一/三线城市 ±15% 浮动
5. **预算假设**：用户明确要求 400 元以内，因此按比例分配到 4 项；驱虫/疫苗不削减，其余按比例压缩并给出替代方案

> 以上如有不符请直接告知，会重新调整。
