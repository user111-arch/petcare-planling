# 智能养宠规划师 pet-care-planning 🐾

> 根据宠物品种、体重、年龄等信息，自动生成月度养宠规划，告诉你**每月花多少钱、喂多少克粮、哪些日子驱虫体检、每天陪玩多久**，新手也能直接照着做。

## 一、解决什么痛点

每个养宠的人，尤其是新手，都遇到过：

- 不知道一个月要准备多少钱 → 超支就开始省狗粮，反而害了宠物；
- 自己定了预算不知道各项怎么分配 → 省了驱虫疫苗钱反而是最大坑；
- 疫苗/驱虫记不住 → 漏打了慌慌补打，或重复买药浪费钱；
- 狗粮喂多少凭感觉 → 少了瘦多了胖，肥胖直接把英短/金毛喂出关节病；
- 不知道品种高发疾病（柯基 IVDD、英短 PKD、金毛 CHD）→ 发现时已经不可逆。

`pet-care-planning` 把这件事变简单：**信息采集 → 知识库推断 → 预算/饮食/健康/陪伴四模块 → 行动清单**。所有数字来自内置知识库（已填充 20 个常见品种详细数据，未收录品种明确告知不编造），不靠拍脑袋。

## 二、核心功能

1. **多方式输入**：支持"我养了只英短 3 岁 6kg"自然语言或品种名+体重清单，信息不足时先列推断值让用户确认。
2. **确定性知识库骨架**：`scripts/pet_care_core.py` 从合并版 MD 加载品种数据，Python 脚本解析而非模型即兴发挥。
3. **品种分级推断**：必填追问 / 可推断先确认 / 增强项跳过，避免用户被 20 个问题劝退。
4. **四大模块直给行动项**：喂多少克粮、驱虫做不做、开销哪项最多、运动多久，不写原理不推公式。
5. **功能性需求叠加**：减肥、美毛、关节护理、泌尿护理、化毛等需求按 nutrition.md 规则叠加营养素和补给（热量 -20%、纤维 +5%、葡萄糖胺 500mg 等）。
6. **精简输出模板**：40-60 行以内、4 个固定模块、表格优先、可勾选行动清单，用户一眼知道做什么。
7. **自定义预算分配**：用户提供月度预算后，对比品种标准开销生成差额提示，按比例分配到各项并给出降级/升级建议（驱虫疫苗不可削减）。
8. **防幻觉约束**：`knowledge/constraints.md` 定义强制脚本加载、不编造数据、不过度生成等规则，生成前逐条自查。

## 四、目录结构

```
pet-care-planning/
├── SKILL.md                      # 主指令文件（必需）：触发条件、执行流程、知识库路径、输出模板
├── readme.md                     # 本文件：项目说明与设计思路
├── scripts/                      # 确定性 Python 脚本（单文件整合版）
│   └── pet_care_core.py          # 核心脚本：枚举/数据模型/宠物档案/知识库加载/verify/merge-breeds/tidy-md 三合一
├── knowledge/                    # 猫狗知识库（品种合并版 MD 是唯一真源）
│   ├── dog_breeds.md             # 合并版犬类品种库（10 个已填充，breed_id 升序）
│   ├── cat_breeds.md             # 合并版猫类品种库（10 个已填充，breed_id 升序）
│   ├── nutrition.md              # 营养标准：热量公式/营养素/喂食指南/功能性调整规则
│   ├── health.md                 # 健康标准：疫苗/驱虫/美容/体检（猫犬分档）
│   └── constraints.md            # 行为约束（防幻觉/异常处理/安全红线）
└── examples/                     # 输出示例
    ├── example1-talk.md # 大型犬，无特殊需求
    ├── example2-photo.md # 小型犬，照片输入识别品种+体型
    ├── example3-budget.md # 中型猫，猫双高发需求叠加
    ├── example4-test.md # 信息不完整场景
    └── example5-multi-turn dialogue.md # 无毛猫品种特异性场景
```

## 五、怎么用

发布到 AstronClaw / SkillHub 后，直接自然语言触发，例如：

- "我有一只英短，3 岁，6kg，帮我写一份宠物预算"
- "柯基一个月花多少钱"
- "金毛每天喂多少克粮"
- "养宠规划：4 岁威尔士柯基，12kg，要减肥+护关节"

Skill 会按 `SKILL.md` 第四步的精简模板输出 4 模块方案：🍖本月喂什么 → ✅本月做什么 → 💰月度开销 → ⚠️注意事项。

用户可提供自定义月度预算（如"我预算 500 元"），Skill 会对比品种标准开销，在月度开销模块展示标准 vs 预算对比表，并给出降级/升级建议。

本地可运行脚本做知识库验证：

```bash
# 验证知识库加载（品种/营养/健康标准全通过才 PASS）
python3 scripts/pet_care_core.py verify

# 合并单品种 MD 为合并版（编辑单品种文件后重跑）
python3 scripts/pet_care_core.py merge-breeds

# 直接从知识库查品种数据（以 dog_001 金毛为例）
python3 -c "
import sys; sys.path.insert(0, 'scripts')
from pet_care_core import KnowledgeLoader
kl = KnowledgeLoader()
b = kl.load_breed('dog_001')
print(f'体重: {b.adult_weight_min_kg}-{b.adult_weight_max_kg}kg')
print(f'月度开销合计: {b.monthly_cost_total()}元')
print(f'常见健康问题: {b.common_health_issues}')
"

# 按用户自定义预算计算分配方案（以 dog_019 柴犬 + 300 元预算为例）
python3 -c "
import sys; sys.path.insert(0, 'scripts')
from pet_care_core import KnowledgeLoader, plan_budget, format_budget_plan
kl = KnowledgeLoader()
b = kl.load_breed('dog_019')
plan = plan_budget(b.monthly_cost, 300)
print(format_budget_plan(plan))
"```

## 六、鲁棒性设计（应对异常不崩溃）

| 异常                            | 策略                                                                        |
| ------------------------------- | --------------------------------------------------------------------------- |
| 用户只说品种不说体重/年龄/绝育  | 从知识库推断默认值，**先列出确认项**，用户确认后再生成完整报告              |
| 知识库中没有对应品种            | 明确告知"该品种暂未收录"，不编造体重/热量/开销                              |
| 用户只问预算/只问饮食           | **只输出所问模块**，末尾加"如需饮食/健康计划可告诉我"，不生成全套           |
| 推断字段与用户实际不符          | 支持用户修改，重新计算（例：绝育→未绝育，热量系数重算）                     |
| 功能性需求冲突（同时减肥+增肥） | 提示冲突让用户二选一，不折中给出"平均热量"                                  |
| 健康风险/药物建议               | **只引用知识库 `common_health_issues`**，不添加未列疾病；不推荐具体处方药物 |
| 用户未要求生成文件              | 默认对话中直接回复表格，不生成 MD 文件                                      |
| 图片识别品种（未来扩展）        | 识别结果需用户确认 breed_id，不直接凭置信度就生成                           |
| 用户预算低于品种标准            | 按比例分配到各分项，给出降级建议，但驱虫和疫苗不可削减                      |
| 用户预算高于品种标准            | 按比例分配到各分项，给出升级建议（功能性粮/专业美容/增加体检频次）          |

详见 `knowledge/constraints.md` 的"违规自查清单"——输出前逐条过审。

## 九、原创与合规声明

- 本 Skill 的思路、提示词模板、状态机设计、输出模板、约束文档均为原创编写。
- `knowledge/` 目录下的品种数据、营养标准、健康护理标准为公开常识整理（品种体重范围、热量公式 RER=70×kg^0.75、犬猫驱虫疫苗周期），不含受版权保护的第三方配方或数据集。
- 所有健康风险提示和高发疾病为常见品种流行病学常识整理，**不作为医学诊断**；宠物健康异常请立即前往正规宠物医院就诊，本 Skill 不替代兽医诊断与处方。
- 营养计算与饮食建议基于体重范围和生命周期系数给出参考值，实际喂食量以粮品包装建议、宠物体况评分（BCS）和兽医意见为准。
- 药品、疫苗、驱虫产品的实际价格以当地医院/宠物店为准，文档中数值为 2025 年全国中位参考价。
